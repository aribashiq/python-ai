# Module 1 Project: AI Prompt Kit

## About
This project generates AI prompts for a local photography business called BS Studio in Lahore.

## Features
- Creates an Instagram marketing prompt.
- Creates a customer service reply prompt.
- Suggests low-cost AI growth ideas.

## Tools
- Python 3.13
- Ollama
- Gemma 3 1B

## How to Run
Open the terminal in the project folder and run:

```bash
uv run python code/project_m1_prompt_kit.py
```

Enter the business name, type, city, main customers, and monthly budget when asked.
